## Што гэта?

**SoundCloud Android** - натыўны кліент SoundCloud для тэлефона. Сінхранізаваны з [SoundCloud-Desktop](https://github.com/zxcloli666/SoundCloud-Desktop).

Напісаны на **Kotlin + Jetpack Compose + Media3**, працуе натыўна і спажывае мінімум рэсурсаў.

Кліент выходзіць у дзвюх версіях, функцыянал у іх агульны, адрозніваецца толькі знешні выгляд:

> `SoundCloud Full` - Glass-дызайн у стылі дэсктопнай версіі, для тых, хто цэніць бліскучае і магутныя тэлефоны.

> `SoundCloud Lite` - спрошчаны інтэрфейс, які выкарыстоўваўся ў першых версіях, для тых, хто цэніць мінімалізм і слабыя тэлефоны.

## Спампаваць

Перайдзі на [старонку рэлізаў](https://github.com/okeydw/SoundCloud-Android/releases/latest) і спампуй патрэбны `.apk`:

| Файл | Версія |
| --- | --- |
| `SoundCloud-Full-vX.Y.Z.apk` | SoundCloud, Glass-дызайн |
| `SoundCloud-Lite-vX.Y.Z.apk` | SoundCloud Lite, просты інтэрфейс |

**Усталяванне:** адкрый спампаваны файл на тэлефоне і дазволь усталяванне з невядомых крыніц. Далей абнаўленні ставяцца з самой праграмы.

**Патрабаванні:** Android 8.0 (Oreo) або навейшы.

---

## Як увайсці

Далей ідзе аўтарызацыя, праз SoundCloud або па QR-кодзе з Desktop версіі.

1. **QR з дэсктопа (рэкамендавана).** У [SoundCloud-Desktop](https://github.com/zxcloli666/SoundCloud-Desktop) адкрый Налады -> Акаўнт -> Перадаць сесію на іншую прыладу, пасля чаго скануй QR-код.
2. **QR з тэлефона.** На экране ўваходу націсні "Паказаць QR для ўваходу" і адскануй яго там, дзе ты ўжо ўвайшоў.
3. **Праз браўзер.** Кнопка "Увайсці праз браўзер" адкрывае звычайны ўваход SoundCloud. Такая сесія можа зляцець, калі потым увайсці дзесьці яшчэ.

## Функцыянал

### Музыка

- **Хваля і рэкамендацыі** - уласная сістэма рэкамендацый на аснове лайкаў і гісторыі праслухоўвання
- **Пошук** - трэкі, артысты, плэйлісты, альбомы і вайб-пошук (нейрасетка падбірае трэк паводле кантэксту)
- **Плэер** - шафл, паўтор, чарга, тэксты песень, лайкі і дызлайкі
- **Эквалайзер** - гатовыя прэсеты і магчымасць стварыць свой прэсет
- **Плэйлісты** - свае лакальныя плэйлісты з сінхранізацыяй у SoundCloud, публічныя або прыватныя, парадак трэкаў мяняецца перацягваннем і захоўваецца
- **Гісторыя і статыстыка** - час праслухоўвання, топ трэкаў і артыстаў, графік па днях і па гадзінах
- **Профілі** - падпіска і адпіска, спасылкі з профілю SoundCloud
- **SoundCloud Auto (бэта)** - стварэнне сцэнарыяў для падключэння да Bluetooth-прылад

### Афлайн-рэжым

- Спампоўка трэкаў і плэйлістаў, аўтаномны рэжым з кэшам
- Ручная налада ліміту кэша і часу яго скіду
- Агульныя загрузкі і плэйлісты паміж Full і Lite, калі ўсталяваны абедзве версіі (бэта, працуе выбарачна)

### Імпарт (бэта)

- **YouTube / YouTube Music** - лайкі, плэйлісты і альбомы праз Google-акаўнт
- **Яндэкс Музыка** - лайкі, плэйлісты і альбомы па токене
- **Spotify** - лайкі, плэйлісты і альбомы праз client_id

## Стэк

| Слой | Тэхналогіі |
| --- | --- |
| Мова | Kotlin |
| UI | Jetpack Compose, Material 3, Haze (шкло ў Full) |
| Аўдыё | Media3 (ExoPlayer + MediaSession), фонавы сэрвіс з апавяшчэннем |
| Сетка | OkHttp (+ дыскавы кэш), kotlinx.serialization |
| Выявы | Coil (+ Palette для падфарбоўкі пад вокладку) |
| Камера | CameraX + ML Kit (сканер QR у Full), ZXing |
| Захоўванне | SharedPreferences (налады, сесія), JSON-індэксы загрузак і плэйлістаў |

Бэкенд: [SoundCloud-Backend](https://github.com/zxcloli666/SoundCloud-Backend).

Статус хостаў [тут](https://status.soundcloud-desktop.fun/)

**Сумяшчальнасць:** `minSdk 26` (Android 8.0), `targetSdk 35`, `compileSdk 35`.

Поўны спіс змяненняў у [CHANGELOG.md](../../CHANGELOG.md).

## Для распрацоўшчыкаў

**Зборка:** JDK 17, Android SDK 35.

```bash
./gradlew assembleLiteDebug assembleFullDebug   # APK у app/build/outputs/apk/<flavor>/debug/
./gradlew testLiteDebugUnitTest                 # юніт-тэсты
./gradlew lintLiteDebug                         # lint (з baseline: ./gradlew updateLintBaseline)
```

**Зыходнікі:**

| Папка | Што ўнутры |
| --- | --- |
| `app/src/main` | логіка: API, плэер, загрузкі, плэйлісты, імпарт |
| `app/src/shared` | агульныя экраны і дыялогі (налады і г.д.) |
| `app/src/lite` | інтэрфейс Lite |
| `app/src/full` | Glass-інтэрфейс Full |

**Рэліз:** тэг `vX.Y.Z` (павінен супадаць з `versionName`) збірае і падпісвае абедзве версіі адным ключом і публікуе іх з апісаннем з `CHANGELOG.md`.

**Бэкенд:**

| Дамен | Для чаго |
|---|---|
| `api.scnative.space`, `api-star.scnative.space` | API |
| `stream.scnative.space`, `stream-star.scnative.space` | аўдыё |
| `storage.scnative.space`, `storage-star.scnative.space`, `s3.scnative.space` | сховішча трэкаў |
| `images.scnative.space` | вокладкі |
| `pay.scnative.space` | аплата STAR |
| `health.scnative.space` | праверка сувязі |
| `call-*.scnative.space` | «Сетка карыстальнікаў» |
| `*.relay.scnative.space` | рэзервовыя маршруты |
| `soundcloud.com`, `api-v2.soundcloud.com`, `*.sndcdn.com` | прамая загрузка трэка з SoundCloud |

Пратакол уваходу па QR: [qr-link-protocol.md](https://github.com/zxcloli666/SoundCloud-Desktop/blob/main/docs/qr-link-protocol.md) у рэпазіторыі дэсктопа.
