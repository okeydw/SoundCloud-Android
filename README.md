## Что это?

**SoundCloud Android** - нативный клиент SoundCloud для телефона. Синхронизирован с [SoundCloud-Desktop](https://github.com/zxcloli666/SoundCloud-Desktop).

Написан на **Kotlin + Jetpack Compose + Media3**, работает нативно и потребляет минимум ресурсов.

Клиент выходит в двух версиях, функционал у них общий, отличается только внешний вид:

> `SoundCloud Full` - Glass-дизайн в стиле десктопной версии, для тех, кто ценит блестяшки и мощные телефоны.

> `SoundCloud Lite` - упрощённый интерфейс который использовался в первых версиях, для тех, кто ценит минимализм и слабые телефоны.

## Как войти

Дальше идёт авторизация, через SoundCloud, либо по QR-коду с Desktop версии

1. **QR с десктопа (рекомендовано).** В [SoundCloud-Desktop](https://github.com/zxcloli666/SoundCloud-Desktop) открой Настройки -> Аккаунт -> Передать сессию на другое устройство, После чего сканируем QR-код.
2. **QR с телефона.** На экране входа нажми "Показать QR для входа" и отсканируй его там, где ты уже вошёл.
3. **Через браузер.** Кнопка "Войти через браузер" открывает обычный вход SoundCloud. Такая сессия может слетать, если потом войти где-то ещё.

## Функционал

### Музыка

- **Волна и рекомендации** - своя система рекомендаций на основе лайков и истории прослушивания
- **Поиск** - треки, артисты, плейлисты, альбомы и вайб-поиск (нейронка подбирает трек, согласно контексту)
- **Плеер** - шафл, повтор, очередь, текст песен, лайки и дизлайки
- **Эквалайзер** - готовые пресеты и возможность создания своего пресета
- **Плейлисты** - свои локальные плейлисты с синхронизацией в SoundCloud, публичные или приватные, порядок треков меняется перетаскиванием и сохраняется
- **История и статистика** - время прослушивания, топ треков и артистов, график по дням и по часам
- **Профили** - подписка и отписка, ссылки из профиля SoundCloud
- **SoundCloud Auto (бета)** - создание сценариев для подключения к Bluetooth-устройствам

### Оффлайн режим

- Скачивание треков и плейлистов, автономный режим с кэшем
- Ручная настройка лимита кеша и времени его сброса
- Общие загрузки и плейлисты между Full и Lite, если стоят обе версии (бета, работает выборочно)

### Импорт (бета)

- **YouTube / YouTube Music** - лайки, плейлисты и альбомы через Google аккаунт
- **Яндекс Музыка** - лайки, плейлисты и альбомы по токену
- **Spotify** - лайки, плейлисты и альбомы через client_id

## Стек

| Слой | Технологии |
| --- | --- |
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3, Haze (стекло в Full) |
| Аудио | Media3 (ExoPlayer + MediaSession), фоновый сервис с уведомлением |

Полный список изменений в [CHANGELOG.md](CHANGELOG.md).

## Для разработчиков

**Сборка:** JDK 17, Android SDK 35.

```bash
./gradlew assembleLiteDebug assembleFullDebug   # APK в app/build/outputs/apk/<flavor>/debug/
./gradlew testLiteDebugUnitTest                 # юнит-тесты
./gradlew lintLiteDebug                         # lint (с baseline: ./gradlew updateLintBaseline)
```

**Исходники:**

| Папка | Что внутри |
| --- | --- |
| `app/src/main` | логика: API, плеер, загрузки, плейлисты, импорт |
| `app/src/shared` | общие экраны и диалоги (настройки и т.д.) |
| `app/src/lite` | интерфейс Lite |
| `app/src/full` | Glass-интерфейс Full |

**Релиз:** тег `vX.Y.Z` (должен совпадать с `versionName`) собирает и подписывает обе версии одним ключом и публикует их с описанием из `CHANGELOG.md`.

**Бэкенд:**

| Домен | Для чего |
|---|---|
| `api.scnative.space`, `api-star.scnative.space` | API |
| `stream.scnative.space`, `stream-star.scnative.space` | аудио |
| `storage.scnative.space`, `storage-star.scnative.space`, `s3.scnative.space` | хранилище треков |
| `images.scnative.space` | обложки |
| `pay.scnative.space` | оплата STAR |
| `health.scnative.space` | проверка связи |
| `call-*.scnative.space` | «Сеть пользователей» |
| `*.relay.scnative.space` | резервные маршруты |
| `soundcloud.com`, `api-v2.soundcloud.com`, `*.sndcdn.com` | прямая загрузка трека с SoundCloud |

Протокол входа по QR: [qr-link-protocol.md](https://github.com/zxcloli666/SoundCloud-Desktop/blob/main/docs/qr-link-protocol.md) в репозитории десктопа.
