# Редизайн SoundCloud-Android в стиле SoundCloud-Desktop (Glass UI)

Ты — senior Android-разработчик (Kotlin, Jetpack Compose, Media3). Работаешь в репозитории **okeydw/SoundCloud-Android**.

**Цель:** сделать «Full»-версию интерфейса, о которой говорит README. Нужно перенести визуальный язык SoundCloud-Desktop («Glass UI», главная «Течение») на телефон и не сломать воспроизведение, загрузки, лайки и вход. Композиция, иерархия и материалы должны совпадать с макетами в `docs/redesign/`, точность до пикселя не нужна. Новых функций сверх описанного ниже не добавляй.

## 2. Жёсткие ограничения

- **Меняется только слой UI.** ExoPlayer/MediaSession, `ScDataSource`, `Downloads`, `Likes`/`Dislikes`, `Api` и сессию не трогай. Исключения прямо названы ниже.
- **minSdk 26 остаётся.** На Android 8.0 всё работает без блюра.
- **Акцент задаёт пользователь** (`Prefs.accent`, RGB-пикер, импорт тем). Никакого хардкода `#FF5500`: glow, hover и тинты выводятся из акцента.
- **Обои пользователя** (`Prefs.backgroundImage` / `AppBackground`) не заливай сплошным цветом. Атмосфера и стекло ложатся поверх.
- **Все строки — в `strings.xml` на 9 языках** (en, ru, be, zh, de, fr, es, tr, ko). Русские и английские формулировки бери из `ru.json`/`en.json` десктопа.
- **Доступность:** у каждой иконки-кнопки есть `contentDescription` (сейчас его нет ни у одной из 75 иконок), зона нажатия ≥ 48 dp.
- **Никакого `Random` в композиции.** Звёзды, «дыхание» плиток и зерно детерминированы (сид).
- Если эндпоинт бэка отвечает не так, как описано, контракт не выдумывай. Сверься с кодом десктопа и оставь фолбэк.
- Если нужно, обнови Compose BOM, Kotlin и AGP до совместимых версий отдельным коммитом.

## 4. Стекло и атмосфера на Android

- **Настоящий backdrop-blur — максимум на 1–3 «плавающих» поверхностях экрана:** мини-плеер, таб-док, верхние кнопки плеера и волны.
  - Библиотека — Haze (`dev.chrisbanes.haze`), последняя стабильная версия.
  - Сверься с её документацией: в 1.x модификаторы `hazeSource`/`hazeEffect`, в 2.x — `hazeSource` + `hazeBlur` из модуля `haze-blur`.
  - `hazeSource` вешай на фон и скроллящийся контент корня экрана.
- **Карточки в списках и на главной — стекло без блюра:** градиент, граница, блик и тень, как `.glass-flat` на десктопе.
- **API < 31 и режим «Лёгкий» — без блюра.** Вместо него тонированный скрим `rgba(22,22,26,0.82)`, как `[data-perf="light"]` на десктопе. В трекере Haze есть баги RenderScript-блюра на старых API: «залипший» кадр при скролле и пустой рендер (issues #1360, #1366, #1368). Поэтому там его не включай.
- **Атмосфера — `ui/glass/Atmosphere.kt`.**
  - Три больших радиальных градиента с `BlendMode.Screen`. Blur-фильтр не нужен: радиальный градиент и так мягкий.
  - Рисуй их в том же Canvas/слое, что и фон с обоями, иначе Screen не смешается с обоями.
  - Цвет берётся из контекста: жанр текущего трека, топ-жанры саундпринта или Palette обложки (`rememberArtworkColor`).
  - Дрейф медленный (translate, 24–36 с). Значение анимации читай внутри `drawBehind`, чтобы не было рекомпозиций.
- **Звёздное поле — `StarField.kt`.** 30–46 точек и четырёхлучевых звёзд, позиции по сид-формуле из `StarField.tsx`. Мерцание — только в режиме «Максимум».
- **Зерно** (опционально) — тайл шума с непрозрачностью 4% на мини-плеере.

## 5. Режимы эффектов = Full / Lite

README обещает Full и Lite. Сделай это одним приложением: настройка «Оформление → Эффекты», зеркально `lib/perf.ts` десктопа.

| Режим | Что включено |
|---|---|
| Максимум | блюр доков, 3 орба с дрейфом, мерцающие звёзды, пульс-кольца, отражение волны |
| Баланс | блюр ×0.5, 2 орба, звёзды без мерцания, без свечения частиц |
| Лёгкий (= Lite) | без блюра (скрим), статичный фон, никаких idle-анимаций |

По умолчанию — «Лёгкий», если SDK < 31 или `ActivityManager.isLowRamDevice`, иначе «Максимум». Все бесконечные анимации ставь на паузу, когда приложение не в STARTED или ничего не играет.

## 6. Производительность — обязательно

- `NowPlaying.position` читается только в листовых компонентах и только в draw-фазе (`drawBehind` / `drawWithCache` / `graphicsLayer`). `NowPlayingScreen` и корни экранов не должны рекомпозироваться 4 раза в секунду. Проверь recomposition counts в Layout Inspector.
- Ленивые списки и сетки — с `key = urn` и `contentType`.
- Бесконечные анимации в строках списка разрешены только у текущего трека.

  - «таблетка» под активной вкладкой плавно едет (`animateDpAsState`);
  - иконка активной вкладки — с акцентным свечением.
- **`Waveform`** — один компонент для деки, плеера и волны. Параметры: высота, число баров, отражение.
- **Мелкие компоненты:** `PlayOrb`, `GlassSurface`, `GlassPill`, `GenreDot`, `LivePill`, `SectionHeader`, `EmptyState` (§5.13), `Skeleton`.
- **Структура пакетов:** `ui/theme`, `ui/glass`, `ui/home`, `ui/wave`, `ui/search`, `ui/library`, `ui/player`, `ui/login`. Разбей `MainActivity.kt` (~2200 строк) и `LibraryScreen.kt` (~1850).

## 10. Светлая тема

Glass-дизайн тёмный. При `Prefs.theme = "light"`:

- стекло — white 0.72–0.85, текст тёмный;
- орбы — с половинной непрозрачностью, без Screen-смешивания;
- свечения мягче.

Белого текста на светлом фоне быть не должно.

## 12. Проверка перед сдачей

- **Сборка:** `./gradlew assembleDebug lint` без новых ошибок. В проекте `abortOnError = false`, поэтому отчёт lint читай вручную.
- **Эмуляторы:**
  - API 26 (без блюра), API 31+, API 35;
  - экраны 360×800 и 412×915 dp;
  - тёмная и светлая тема;
  - своя картинка-фон;
  - белый акцент: иконки на акценте должны быть чёрными.

  - во время воспроизведения плеер не рекомпозируется целиком каждые 250 мс;
