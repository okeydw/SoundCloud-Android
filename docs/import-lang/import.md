# Импорт музыки

Импорт находится в **Настройки -> Импорт (бета)**. 
Как это работает:

- **Spotify и Яндекс Музыка.** Приложение не копирует оригиналы, а ищет такие же треки на SoundCloud по названию и исполнителю.
- **YouTube.** Можно взять сам трек с YouTube или найти похожий на SoundCloud.
- Треки и плейлисты, которые были взяты напрямую с YouTube синхронизированы с SounCloud не будут
- Если в плейлисте будет больше 500 треков, то будут созданы отдельные плейлисты
- Токены и сессии хранятся только на телефоне.

## По ссылке

1. Скопируй ссылку на трек, плейлист или альбом.
2. Вставь её в поле "Импорт по ссылке". 
3. Выбери, куда добавить, и нажми "Импортировать".

Без входа в аккаунт работают открытые ссылки. Для закрытых плейлистов и лайков подключи аккаунт ниже.
> Spotify! 
> Без входа из плейлиста читаются только первые 100 треков. 


## Spotify

1. Открываем [панель разработчика Spotify](https://developer.spotify.com/dashboard) и входим под своей учёткой.
2. Нажми **Create app**. Название и описание любые.
3. В **Redirect URIs** добавляем версии приложения, можете сразу две, только делайте это раздельно:
   - Lite: `com.scd.android://spotify-auth`
   - Full: `com.scd.android.full://spotify-auth`
4. В **Which API/SDKs are you planning to use?** отмечаем **Web API** и сохраняем.
5. Открываем **Settings -> User Management** и добавляем email аккаунта Spotify, из которого будешь импортировать.
6. Копируем **Client ID** (32 буквы и цифры) и вставляем его в приложении: **Импорт -> Spotify -> Client ID**.
7. Кнопка сменится на "Авторизовать приложение", нажимаем по ней и переходим в окно авторизации, где нажимаем подтвердить.

Если всё правильно, то должно отобразиться Имя и иконка профиля вашего Spotify, дальше вы можете импортировать лайки и закрытые плейлисты

Важно:

- Приложение в режиме разработки Spotify работает только для аккаунтов из User Management. Владельцу приложения в панели нужен Spotify Premium, иначе Spotify ответит 403.
- Если Spotify отклонил Client ID, под полем появится ошибка: проверь ID и Redirect URI в панели.

Если поле пустое, кнопка "Войти в Spotify" открывает встроенное окно входа. Это проще, но работает не всегда.

## YouTube

1. Открываем **Импорт -> YouTube (Music)** и нажми **Добавить аккаунт**.
2. Войди в Google в открывшемся окне. Окно закроется само, и появятся имя и аватар аккаунта.
3. **Импортировать лайки** ищет понравившиеся видео на SoundCloud и собирает их в плейлист.

По ссылке можно импортировать трек или плейлист. Есть два режима:

- **Взять с YouTube.** Звук скачивается с YouTube, плейлист остаётся только на телефоне.
- **Найти похожие в SoundCloud.** Ищет такие же треки на SoundCloud.

Если Google пишет, что браузер небезопасен - используем VPN.

## Yandex Music

1. Открываем **Импорт -> Яндекс Музыка** и нажимаем **Войти через Яндекс**.
2. Откроется браузер. Выбираем нужный аккаунт.
3. Копируем адрес страницы, на которую тебя перекинет, после чего возвращаемся в приложение и нажимаем кнопку "Вставить ссылку"
4. **Импортировать лайки** переносит любимые треки.

Есть автоматический вход, можете попробовать.

Чтобы сменить аккаунт, нажимаем **Забыть аккаунт** и войди заново.
